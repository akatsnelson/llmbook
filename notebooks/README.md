# Ноутбуки к книге

Ноутбук не пересказывает главу. Он берёт один механизм и превращает его в опыт: вы заранее знаете, что
подадите на вход, что будете мерить и какой ответ правильный, а потом проверяете это на деле.

## Как устроен каждый ноутбук

- В начале стоят вопрос и ожидаемый результат: попробуйте ответить сами до запуска.
- Первая ячейка фиксирует случайные зёрна и печатает версии библиотек, поэтому числа повторяются от запуска
  к запуску.
- Ноутбук проходит целиком по **Restart Kernel → Run All** на обычном процессоре, без видеокарты и сети.
- Ответ проверяется `assert`, допуском или контрольной суммой: если что-то разошлось, ячейка упадёт.
- В каждом есть одна намеренно сломанная версия или задание найти ошибку.
- В конце — таблица, которая связывает переменные ноутбука с объектами настоящих библиотек.

Ноутбуки 12, 13 и 18 строят цепочку выпусков BookLM: 12 пишет манифест `booklm-rag-v1`, 13 — `booklm-tools-v1`
поверх него, 18 — `booklm-guarded-v1`. Манифесты складываются в `notebooks/artifacts/`, которого нет в
репозитории: он появляется при запуске. Поэтому запускайте эти три ноутбука по порядку.

## Карта ноутбуков

В каталоге 22 ноутбука. Все они выполняются на CPU без сети и GPU; аппаратная часть главы 15 вынесена
отдельно (см. ниже).

Отдельных ноутбуков для экспорта ONNX с KV-кэшем, генератора нагрузки главы 17 и многопроцессного шага
BookLM в репозитории нет.

## Ноутбуки и каталог labs/

Длинные листинги книги сокращены до сути; полные версии лежат в `labs/chNN/*.py`. Большинство ноутбуков глав 3–13
и 15–17, а также `14_inference_labs.ipynb` берут код из этих файлов. Каждый файл можно запустить и отдельно, из
корня репозитория: `python labs/ch08/lora_train_merge.py`. Нужен Python 3.10 или новее и PyTorch для
CPU; `labs/ch14/onnx_decoder_step.py` при установленных `onnx` и `onnxruntime` дополнительно сверяет граф с
ONNX Runtime.

## Локальная проверка

```bash
python scripts/check_notebooks.py
python scripts/check_notebooks.py --execute
```

Первый запуск проверяет структуру JSON и синтаксис Python-ячеек. Второй выполняет ячейки каждого ноутбука по
порядку в общем пространстве имён; так их проверяем и мы перед каждым выпуском книги.
