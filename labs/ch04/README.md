# labs/ch04 — архитектура трансформера

Полные версии листингов и опыты главы 4 «Архитектура трансформера». В книге листинги печатают числа и формы;
здесь те же вычисления закреплены утверждениями `assert`. Запуск из корня репозитория:
`python labs/ch04/<файл>.py`.

| Файл | Раздел книги |
|---|---|
| `attention_checks.py` | вся глава: все числа и формы листингов |
| `noise_mask.py` | 4.3 «Причинная маска»: внимание без маски учится на шуме |
| `block_parts.py` | 4.4–4.6: зачем головы, полносвязная ветвь и остаточный путь |
| `tiny_decoder_lm.py` | 4.7 «Декодерный блок и модель» |
| `rope_pairs.py` | 4.8.3 «Частоты пар», 4.8.4 «Раскладка пар», 4.8.6 «ALiBi» |
| `booklm_model.py` | 4.5–4.10: полная BookLM и её 6 622 464 параметра |
| `linear_attention.py` | 4.11 «Линейное внимание» |
| `ssm_selective_copy.py` | 4.12 «Модели пространства состояний»: выборочное копирование (около 5 минут) |
