# BookLM — сквозная модель книги

Маленький русский сказочник на 6 622 464 параметра. Архитектура — из главы 4: шесть блоков, ширина 256,
8 голов запроса и 2 головы ключей и значений (GQA), RoPE, RMSNorm, SwiGLU 768, связанные веса вложений и
выхода, контекст 512 токенов. Код модели — `booklm/model.py`, загрузка, генерация и перплексия —
`booklm/lab.py`, опыты из рубрик «А теперь на нашей модели» — `booklm/experiments/`. Всё здесь считается на
обычном процессоре за секунды.

```python
from booklm.lab import load, generate
tok, model = load("base")
print(generate(tok, model, "Однажды", seed=0))

tok, model = load("instruct")
print(generate(tok, model, "Напиши сказку про кота и рыбу.", chat=True, seed=1))
```

## На чём обучена

Корпус — 68 958 детских историй TinyStories (Eldan, Li, 2023, arXiv:2305.07759), переведённых на русский
моделью Qwen3-8B (скрипт `booklm/translate_llm.py`, нужны видеокарта и vLLM). Сами истории синтетические: их сочинили GPT-3.5 и GPT-4. Последние 689 историй отложены
для проверки, модель их не видела.

| | |
|---|---|
| токенизатор | байтовый BPE, 8192 токена, 1,45 токена на слово |
| служебные токены | `<pad>`=0, `<bos>`=1, `<eos>`=2, `<|user|>`=3, `<|assistant|>`=4 |
| обучающих токенов | 12 507 970 |
| предобучение | 3051 шаг по 64 × 512 токенов, около 100 млн токенов (8 проходов), AdamW, lr 2·10⁻³ с косинусным спадом |
| потеря на отложенных историях | 9,04 на шаге 0 → 1,93 в конце (перплексия 6,96) |
| дообучение | LoRA r=16, α=32 на 9752 парах «просьба → история», 2 эпохи, 454 656 обучаемых параметров |
| железо | одна NVIDIA GB10, около 25 минут предобучения и 1 минута LoRA |

## Файлы

| файл | что это |
|---|---|
| `tokenizer.json` | токенизатор |
| `booklm-base.pt` | веса после предобучения: продолжает текст |
| `booklm-instruct.pt` | веса после LoRA, адаптер уже влит: выполняет просьбы в формате `<bos><|user|>просьба<|assistant|>` |
| `booklm-instruct-lora.pt` | сам адаптер LoRA (матрицы A и B) |
| `steps/stepNNNNNN.pt` | веса на шагах 0, 100, 762, 1000 и 1525 (bfloat16), чтобы смотреть, как модель учится; шаг 0 — это `booklm-base-init` из книги |
| `train_log.jsonl` | журнал предобучения: потеря, скорость обучения, норма градиента, образцы текста |
| `lora_log.jsonl`, `lora_summary.json` | журнал и итог дообучения |
| `data/train.bin`, `data/val.bin` | обучающие и отложенные токены (uint16) |
| `data/sft.jsonl` | пары «просьба → история» для дообучения |
| `hf/instruct-fixed` | инструктивная модель в формате Hugging Face (`LlamaForCausalLM`), выгружена `booklm/export_hf.py` |
| `hf/base`, `hf/instruct` | черновые выгрузки в формате Hugging Face: глава 17 разбирает на них три дефекта выгрузки (родитель записан только путём, логиты не сверены с сохранённым файлом, шаблон диалога без `<bos>`); для работы берите `hf/instruct-fixed` |
| `experiments/` | выводы и небольшие веса опытов из `booklm/experiments` и `labs/` |

Через Hugging Face:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer
tok = AutoTokenizer.from_pretrained("models/booklm/hf/instruct-fixed")
model = AutoModelForCausalLM.from_pretrained("models/booklm/hf/instruct-fixed")
```

## Чего от неё ждать

Базовая модель пишет связные короткие сказки с диалогами, но путает род и падежи («большую мяч») и
теряет героев к концу. Инструктивная модель всегда отвечает новой сказкой и обычно берёт героя из
просьбы, если это частое слово (кот, собака, девочка), а редкие (ёжик, воздушный змей) подхватывает
примерно в половине случаев. Дообучение дольше (6 эпох) и с большим рангом (r=64) это почти не меняет:
в доле ответов, где встречаются главные слова просьбы, 24 % у r=16 за 2 эпохи, 27 % у r=16 за 6 эпох и
29 % у r=64 (скрипт проверки — `booklm/eval_follow.py`).

Файлы весов хранятся в Git LFS: после клонирования выполните `git lfs pull`.

## Как модель получена

Обучение шло на видеокарте NVIDIA GB10; скрипты `booklm/train.py` и `booklm/sft_lora.py` рассчитаны на
CUDA. Повторять их для книги не нужно: результат лежит здесь. Порядок шагов:

1. `booklm/translate_llm.py` — перевод TinyStories моделью Qwen3-8B (vLLM, видеокарта);
2. `booklm/tokenizer_train.py` — байтовый BPE на 8192 токена;
3. `booklm/prepare.py` — `data/train.bin`, `data/val.bin`;
4. `booklm/train.py` — предобучение (`booklm-base.pt`, `steps/`, `train_log.jsonl`);
5. `booklm/make_sft.py` — пары «просьба → история» (`data/sft.jsonl`);
6. `booklm/sft_lora.py` — LoRA и слияние (`booklm-instruct*.pt`);
7. `booklm/export_hf.py` — выгрузка в формат Hugging Face (`hf/instruct-fixed`).

Сырой перевод (шаги 1–3) в репозиторий не входит, только токены. Дообучить BookLM на своих парах можно и
на процессоре: функции `train_lora` и `merged_state` из `booklm/experiments/ch17.py`.
