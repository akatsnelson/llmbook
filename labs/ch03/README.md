# labs/ch03 — токенизация и эмбеддинги

Полные версии листингов и опыты главы 3 «Токенизация и эмбеддинги». В книге листинги печатают числа; здесь
те же вычисления закреплены утверждениями `assert`. Запуск из корня репозитория: `python labs/ch03/<файл>.py`.

| Файл | Раздел книги |
|---|---|
| `text_to_batch_checks.py` | вся глава: все числа листингов от байтов до пакета |
| `bpe_tokenizer.py` | 3.2 «Кодирование парами байтов», 3.3 «Кодирование и декодирование» |
| `scaffold_tokens.py` | 3.5.3 «Строительные токены», 3.5.5 «Чистка словаря» (около полутора минут) |
| `noncanonical_generation.py` | 3.5.6 «Неканоническая токенизация» |
| `entropy_patches.py` | 3.5.7 «Модели без токенизатора», 3.5.8 «Участки по энтропии» |
