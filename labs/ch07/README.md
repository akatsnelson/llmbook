# labs/ch07 — предобучение BookLM

Полные версии листингов главы 7 «Предобучение». В книге листинги печатают числа; здесь те же вычисления
закреплены утверждениями `assert`. Каждый файл самостоятелен и считается на CPU. Запуск из корня
репозитория: `python labs/ch07/<файл>.py`.

| `minhash_toy_corpus.py`, `packing_document_mask.py` | 7.2 «Подготовка обучающих данных»: MinHash, конвейер, упаковка, загрязнение |

## Что должна выдержать любая реализация главы

Этот список раньше стоял в тексте главы; ноутбук `07_pretraining.ipynb` проходит его на полной BookLM.

1. 6 622 464 параметра в формах главы 4; таблица токенов и выходной слой — один тензор.
2. Стартовая ошибка после инициализации отличается от ln 8192 меньше чем на 0,1 (у полной BookLM 9,058).
3. Градиент маленькой сети совпадает с центральной разностью в float64 с относительной ошибкой меньше 1e-7.
4. Правка одного документа не сдвигает выходы другого документа в том же окне (тест влияния).
5. Градиент, накопленный по микропакетам с разным числом токенов, совпадает с градиентом целого пакета
   в допуске 1e-6.
6. Шаг с переполнением не трогает параметры, моменты, номер шага и планировщик, а масштаб делит пополам.
7. «Обучить k, сохранить, загрузить, обучить j» побитно совпадает с непрерывным прогоном на CPU (на GPU —
   в записанном допуске), а сохранение «только веса» видно по расхождению.
8. Валидационная потеря записана вместе с шагом и числом увиденных токенов, ниже стартовой и не растёт,
   пока падает обучающая.
9. Контрольные продолжения фиксированных начал записаны и не меняются при повторном запуске.
10. Загрузка с чужим хешем родительских весов падает с ошибкой.
