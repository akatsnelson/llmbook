# labs/ch05 — архитектуры современных LLM

Полные версии листингов и опыты главы 5 «Архитектуры современных LLM». Запуск из корня репозитория:
`python labs/ch05/<файл>.py`.

| Файл | Раздел книги |
|---|---|
| `chapter_checks.py` | вся глава: все числа листингов в виде `assert` |
| `architecture_passport.py` | 5.2 «Паспорт модели», 5.4.3 «Общее и активное число параметров» |
| `moe_layer.py` | 5.4 «Смесь экспертов»: маршрут токена и групповой проход |
| `moe_capacity_balance.py` | 5.4.4 «Перегрузка экспертов и балансировка нагрузки» |
| `moe_train.py`, `moe_prune_merge.py` | 5.4.5 «Удаление и слияние экспертов» (около часа и около 15 минут; готовые веса уже лежат в `models/booklm/experiments`) |
| `attention_sinks.py` | 5.5.2 «Стоки внимания и выходные ворота» (около двух минут) |
| `gated_deltanet.py` | 5.5.7 «Блок Qwen3.5»: слой Gated DeltaNet |
| `masked_diffusion_toy.py` | 5.8.1 «Маскированная диффузия», 5.8.2 «Генерация открытием масок» |
| `masked_diffusion_tales.py` | 5.8 «Диффузионные языковые модели»: опыт на сказках BookLM (10–15 минут) |
